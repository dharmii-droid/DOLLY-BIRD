# DOLLY BIRD — Vercel project

## Run locally
1. Install Node.js 18 or newer.
2. In this folder, run `npm install`.
3. Run `npm run dev`.
4. Open http://localhost:3000.

## Deploy to Vercel
1. Create a GitHub repository and upload the contents of this folder.
2. In Vercel, choose **Add New → Project** and import that repository.
3. Keep the detected Next.js framework settings.
4. Click **Deploy**. No environment variables are required.

## Personal assets
- `public/dolly-face.jpg` is the uploaded selfie.
- `public/dolly-music.mp3` is the uploaded audio clip.
The audio is set to loop. Browsers require a user gesture before sound can start, so it begins when the player taps **START GAME**.

## Controls
Tap/click the game area or press SPACE / Arrow Up to flap. The sound button mutes/unmutes the soundtrack.
